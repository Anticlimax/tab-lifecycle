# Tab Lifecycle

Public release documents for **Tab Lifecycle / 标签页生命周期**, a local-first Chrome extension that sleeps long-inactive tabs, asks for review before closing them by default, and keeps local recovery records.

## Public documents

- [Privacy Policy](docs/privacy-policy.md)
- [Permission rationale](docs/permission-rationale.md)
- [Chrome Web Store listing copy](docs/store-listing.md)

The privacy policy is published here as the public policy link for the Chrome Web Store listing.

## Data boundary

The current extension operates locally in Chrome. It has no account, backend, telemetry, content scripts, host permissions, or network requests. See the privacy policy for the complete disclosure.
